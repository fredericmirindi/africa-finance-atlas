# Publish Africa Finance Atlas

Publishing folder: / (root)

## Website entry file
Upload the prepared index.html into the repository root on main. It is the supplied 3D-banknote website, unchanged apart from its deployment filename.

The file contains its CSS, JavaScript, data and uploaded-banknote image assets. Separate source PDFs are not required to run it. Existing external reference images and data APIs remain external dependencies. Do not upload unrelated documents from the conversation.

The .nojekyll file is intentionally empty. It tells GitHub Pages not to process the static website with Jekyll.

## Enable publication after uploading index.html
1. Open repository Settings > Pages.
2. Under Build and deployment, set Source to Deploy from a branch.
3. Select main and / (root), then Save.
4. Wait for the Pages deployment to succeed and use the URL shown in Settings > Pages.

Expected default URL after successful publication:
https://fredericmirindi.github.io/africa-finance-atlas/

Adding this guide and .nojekyll does not upload index.html, enable Pages or prove the website is live. Those steps must be completed and verified separately.

## Publication scope
The repository and published website are public. The banknote pictures embedded in index.html will therefore be public. Source credit does not establish reproduction permission; retain the relevant permissions before public/commercial distribution. Bank and market information has the dates and limitations disclosed in the app. It is an educational atlas, not investment advice or an authenticity service.
